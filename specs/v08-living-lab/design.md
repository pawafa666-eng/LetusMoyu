# 技术与视觉设计

沿用 Vue 3 / TypeScript / Vite / Three.js / CloudBase Event Function / NoSQL。新增 living-content、living-lab、joint-research、institute 和 wallet/ledger 模块，复用学生、论文审稿、合同、活动履历及设备机制。

房间 JSON 保存轻量玩法状态及账本汇总/最近 100 笔；新增 ADMINONLY letus_moyu_ledger 存完整明细，通过同一事务写入。所有变动使用统一记账方法，期初余额从迁移时真实余额建立；账目守恒检查拒绝未归类漏记。账本查询强制当前 UID 与房间成员，分页游标，忽略客户端 owner。

生命周期：迁移 → 自动结算（含联合任务/校友/转化/教师）→ 学生连续研究 → 本人自动收支 → 手动选择 → 账目校验 → 同一事务写房间、明细及回执。公有输出继续删除下划线私有字段与另一玩家私有请求/账本。

联合课题保存两个专业角色工序，各自工作位/学生占用、实际完成时间和成果材料；整合再验收，收益不提前发放。学生请求、故事、校友、转化均为持久状态机。教师带来的学生使用现有完整学生结构并标记 supervisorId，老师可委托自动选题，论文保留审稿与明确版面费确认。

页面新增“实验室生活”：来信/联合课题/故事/校友/教师/转化/实景；“我的科研 → 经费明细”采用摘要、筛选和时间流水，收入蓝色、支出暖红，显示净额与余额，不用饼图替代真实明细。

视觉延续暖白 #faf9f6、正文 #35475b、fafa 蓝 #3478c8、Yizi 粉 #c74686、纸张金 #9b773e；Microsoft YaHei/Noto Sans SC、Lucide 图标。实景低多边形、可旋转、尊重 reduced-motion，设备不足时提供同内容的轻量视图。手机表单单列、按钮可触达、信息逐层展开。

测试覆盖每个状态机的开始/等待/选择/完成/重复操作/越权，账本分拆、迁移、守恒及持久查询。所有新增常量和默认行为在内容文件中集中定义。
